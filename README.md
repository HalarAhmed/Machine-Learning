# Machine Learning Notebooks

This repository contains my personal collection of Jupyter notebooks documenting the implementation of various **Machine Learning algorithms**.  
Each notebook includes two approaches:
- **From Scratch**: Step-by-step implementation to understand the core mathematical intuition.
- **Using Scikit-Learn**: Practical application with Python’s most popular ML library.

---

## 🎯 Purpose
The goal of this repository is to:
- Build a strong foundation in ML by coding algorithms manually plus their implementation in sklearn.
- Serve as a reference for future projects and exam preparation.

---

## 🚀 Algorithms Covered
- **Linear Regression: Simple Linear Regression, Multiple Linear Regression**
- **Gradient Descent: Batch GD, Stochastic GD, Mini-Batch GD**
- **Regularization: Lasso Regularization, Ridge Regulariztion, ElasticNet Regularization**
- **Polynomial Regression**
- **Logistic Regression**
- **K Nearest Neighbors**


- More to be added as I progress.
